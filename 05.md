# 05 — Estimation & Confidence Intervals

## 31. What is a point estimate?

A point estimate is a single value used to estimate an unknown population parameter.

Examples:
- Sample mean estimates population mean μ.
- Sample proportion estimates population proportion p.

---

## 32. What is a confidence interval?

A confidence interval is a range of plausible values for an unknown population parameter, calculated from sample data.

General form:

**Estimate ± Margin of Error**

For a mean with a known/appropriate standard error, a common form is:

**x̄ ± critical value × SE**

---

## 33. What does a 95% confidence interval actually mean?

A 95% confidence level means that if we repeatedly took samples and constructed intervals using the same method, about 95% of those intervals would contain the true population parameter.

It does **not** strictly mean that there is a 95% probability that the fixed parameter is inside this particular interval.

---

## 34. What factors affect the width of a confidence interval?

Main factors:

- **Sample size:** Larger n → narrower interval.
- **Variability:** More variability → wider interval.
- **Confidence level:** Higher confidence → wider interval.
- **Standard error:** Larger SE → wider interval.

---

## 35. What is the difference between standard deviation and standard error?

**Standard deviation (SD):** Measures variability among individual observations.

**Standard error (SE):** Measures variability of an estimator across repeated samples.

For a sample mean:

**SE = s / √n**

So increasing sample size generally decreases the standard error.
