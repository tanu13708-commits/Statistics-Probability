# 09 — Statistics for Machine Learning

## 56. How do you detect and handle outliers statistically?

Common detection methods include:

### IQR Method

Calculate Q1, Q3 and:

**IQR = Q3 - Q1**

Potential outliers are commonly identified below:

**Q1 - 1.5 × IQR**

or above:

**Q3 + 1.5 × IQR**

### Z-score Method

For approximately normal data, unusually large absolute z-scores can flag observations for investigation.

Handling depends on context:
- Correct data-entry errors
- Keep genuine extreme values
- Cap/winsorize when justified
- Transform variables
- Use robust models/statistics
- Remove observations only with a defensible reason

## 57. How does standardization differ from normalization?

### Standardization

Transforms values using:

**z = (x - μ) / σ**

It produces features centered around 0 with standard deviation approximately 1 when μ and σ are computed from the same dataset.

### Normalization

Often means scaling values to a fixed range, commonly [0, 1]:

**x' = (x - min) / (max - min)**

The exact meaning of normalization can vary, so the method should be specified.

## 58. How can statistical concepts help identify data leakage?

Data leakage occurs when information unavailable at prediction time enters model training or evaluation.

Statistical checks can help reveal suspicious patterns such as:
- A feature being extremely predictive
- Unexpectedly large train-test performance differences
- Features containing future information
- Duplicates across train and test sets
- Preprocessing performed using the full dataset before splitting

A key prevention method is to split data appropriately and fit preprocessing steps only on the training data.

## 59. Why are distributions important when analyzing ML datasets?

Understanding distributions helps us identify:
- Skewness
- Outliers
- Class imbalance
- Data quality issues
- Scale differences
- Possible transformations
- Assumption violations

Distribution analysis can influence preprocessing, visualization, statistical testing, and model selection.

## 60. How would you determine whether a change in model performance is statistically meaningful?

A single change in accuracy or another metric does not automatically prove that one model is better.

A better approach is to:
1. Evaluate models on the same appropriate test data or repeated splits.
2. Use repeated cross-validation or repeated experiments when appropriate.
3. Examine the distribution of performance differences.
4. Apply a suitable statistical comparison/test for the evaluation design.
5. Report uncertainty such as confidence intervals.
6. Consider practical significance, not only statistical significance.

For example, with paired predictions on the same observations, a paired procedure may be appropriate depending on the metric and experimental design.
