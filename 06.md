# 06 — Hypothesis Testing

## 36. What is hypothesis testing?

Hypothesis testing is a statistical procedure used to evaluate evidence about a population claim using sample data.

It usually involves:
1. State hypotheses.
2. Choose significance level.
3. Calculate a test statistic.
4. Calculate p-value or compare with a critical value.
5. Make a decision about the null hypothesis.

---

## 37. What are null and alternative hypotheses?

**Null hypothesis (H₀):** Usually represents no effect, no difference, or a specified population value.

**Alternative hypothesis (H₁ or Hₐ):** Represents the effect, difference, or relationship being investigated.

Example:

H₀: μ = 50

Hₐ: μ ≠ 50

---

## 38. What is a significance level?

Significance level, denoted by **α**, is the chosen threshold for rejecting the null hypothesis.

A common choice is α = 0.05.

It represents the maximum Type I error rate we are willing to tolerate under the testing procedure.

---

## 39. What is a p-value?

A p-value is the probability, assuming the null hypothesis is true, of obtaining a test statistic at least as extreme as the one observed, in the direction defined by the test.

A small p-value indicates stronger evidence against H₀.

It is **not** the probability that H₀ is true.

---

## 40. What does statistical significance mean?

A result is statistically significant when the test provides sufficient evidence against H₀ according to a preselected significance level.

For example, if p < 0.05 under a test using α = 0.05, we reject H₀.

Statistical significance does not automatically mean the effect is practically important.

---

## 41. What are Type I and Type II errors?

**Type I error:** Rejecting a true null hypothesis.

**Type II error:** Failing to reject a false null hypothesis.

| Reality | Decision | Error |
|---|---|---|
| H₀ true | Reject H₀ | Type I |
| H₀ false | Fail to reject H₀ | Type II |

---

## 42. What is statistical power?

Statistical power is the probability of correctly rejecting H₀ when a specified alternative is true.

**Power = 1 - β**

where β is the Type II error probability.

Power generally increases with:
- Larger sample size
- Larger true effect
- Lower variability
- Higher significance level

---

## 43. What is the difference between one-tailed and two-tailed tests?

**One-tailed test:** Tests for an effect in one specified direction.

Example: μ > 50.

**Two-tailed test:** Tests for a difference in either direction.

Example: μ ≠ 50.

The choice should be made before examining the results and should follow the research question.
