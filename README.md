# Statistics & Probability for Data Science and Machine Learning

A structured, detailed collection of **Statistics and Probability interview, viva, and ML-preparation questions**.

The repository is organized topic-wise. Every question has its **own Markdown file**, containing:

- Detailed conceptual explanation
- Intuition
- Mathematical perspective
- Examples
- Step-by-step reasoning
- Real-world applications
- Common mistakes
- Machine Learning relevance
- Key takeaways
- Interview-ready answer
- Quick revision

## Study Strategy

For each question:

1. Understand the intuition.
2. Learn the mathematical definition.
3. Solve the example yourself.
4. Check the assumptions and common mistakes.
5. Connect the concept to an ML problem.
6. Practice explaining it in your own words using the interview section.

## Repository Goal

The purpose of this repository is to build a strong foundation in statistics for **data analysis, machine learning, interviews, and practical problem solving**.
