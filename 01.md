# 01 — Probability Fundamentals

## 1. What is probability and how is it interpreted?

Probability measures how likely an event is to occur.

For equally likely outcomes:

**P(A) = Number of favourable outcomes / Total number of possible outcomes**

Its value lies between 0 and 1:
- 0 = impossible
- 1 = certain
- 0.5 = 50% chance

Example: For a fair coin, P(Head) = 1/2.

---

## 2. What are sample space, events, and outcomes?

- **Sample space (S):** Set of all possible outcomes.
- **Outcome:** One possible result.
- **Event:** A set of one or more outcomes.

Example: Rolling a die:

S = {1, 2, 3, 4, 5, 6}

An outcome can be 3. The event of getting an even number is {2, 4, 6}.

---

## 3. What are mutually exclusive and independent events?

**Mutually exclusive events** cannot occur together.

P(A ∩ B) = 0

Example: In one coin toss, Head and Tail are mutually exclusive.

**Independent events** are events where occurrence of one does not affect the probability of the other.

P(A ∩ B) = P(A)P(B)

Example: Results of two separate fair coin tosses.

---

## 4. What is conditional probability?

Conditional probability is the probability of an event occurring given that another event has already occurred.

**P(A|B) = P(A ∩ B) / P(B)**, provided P(B) > 0.

Example: Probability that a student passes given that they attended all classes.

---

## 5. Explain the multiplication and addition rules of probability.

### Multiplication Rule

For any two events:

**P(A ∩ B) = P(A)P(B|A)**

If A and B are independent:

**P(A ∩ B) = P(A)P(B)**

### Addition Rule

**P(A ∪ B) = P(A) + P(B) - P(A ∩ B)**

If A and B are mutually exclusive:

**P(A ∪ B) = P(A) + P(B)**

---

## 6. What is Bayes' theorem and where is it useful?

Bayes' theorem updates the probability of a hypothesis using new evidence.

**P(A|B) = [P(B|A)P(A)] / P(B)**

It is useful in:
- Medical diagnosis
- Spam detection
- Classification
- Fraud detection
- Machine Learning

The key idea is: **new evidence can change our belief about a hypothesis.**

---

## 7. What is the difference between independent and mutually exclusive events?

| Independent | Mutually Exclusive |
|---|---|
| One event does not affect the other | Both cannot happen together |
| P(A ∩ B) = P(A)P(B) | P(A ∩ B) = 0 |
| Can occur together | Cannot occur together |

Important: Two events with positive probability cannot be both independent and mutually exclusive.

---

## 8. What is the law of total probability?

If B1, B2, ..., Bn form mutually exclusive and exhaustive cases, then:

**P(A) = Σ P(A|Bi)P(Bi)**

It is useful when an event can occur through several different cases or groups.

Example: Finding the probability that a product is defective when products come from multiple factories.
