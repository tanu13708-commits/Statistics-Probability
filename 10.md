# 10 — Quick Interview Revision

## Probability
- Probability measures the likelihood of an event.
- Sample space = all possible outcomes.
- Event = collection of outcomes.
- Mutually exclusive: cannot occur together.
- Independent: occurrence of one does not affect the other.
- Conditional probability: probability given some information.
- Bayes' theorem updates a probability using evidence.

## Random Variables
- Discrete → countable values.
- Continuous → values over an interval.
- PMF → discrete probabilities.
- PDF → continuous probability density.
- CDF → P(X ≤ x).
- Expectation → average/mean.
- Variance → squared spread.
- Standard deviation → √variance.

## Distributions
- Bernoulli → one binary trial.
- Binomial → number of successes in n Bernoulli trials.
- Poisson → count of events in a fixed interval.
- Normal → symmetric bell-shaped distribution.

## Descriptive Statistics
- Mean → average.
- Median → middle value.
- Mode → most frequent.
- Range → max - min.
- IQR → Q3 - Q1.
- Skewness → asymmetry.
- Kurtosis → tail heaviness/concentration relative to a reference distribution.

## Sampling
- Population → entire target group.
- Sample → subset.
- Sampling bias → systematic lack of representativeness.
- CLT → sampling mean tends toward a normal distribution under common conditions as sample size grows.

## Estimation
- Point estimate → one estimated value.
- Confidence interval → interval constructed to estimate a population parameter.
- Larger sample → generally narrower CI.
- SD → variability of observations.
- SE → variability of an estimator.

## Hypothesis Testing
- H₀ → null hypothesis.
- Hₐ → alternative hypothesis.
- α → significance level.
- p-value → evidence measure under H₀.
- Type I → reject true H₀.
- Type II → fail to reject false H₀.
- Power = 1 - β.

## Tests
- t-test → compare means under t-test assumptions.
- z-test → normal-based test under relevant assumptions.
- ANOVA → compare multiple group means.
- Chi-square → categorical count data.
- Parametric vs non-parametric → depends on assumptions and data.

## Correlation & Regression
- Covariance → direction of joint variation.
- Correlation → standardized association.
- Pearson → linear association.
- Spearman → rank-based monotonic association.
- Correlation ≠ causation.
- Regression → models a response using predictors.

## Statistics in ML
- IQR/z-score → common outlier screening methods.
- Standardization → center and scale using mean/SD.
- Min-max scaling → maps values to a chosen range.
- Data leakage → information from outside the legitimate training information enters model development.
- Distribution analysis → helps understand data quality and preprocessing.
- Model comparison → use repeated evaluation and uncertainty/statistical comparison where appropriate.
